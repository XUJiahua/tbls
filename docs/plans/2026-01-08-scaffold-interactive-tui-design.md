# Scaffold Interactive TUI Design

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add interactive table selection to `tbls scaffold` command using fzf-style fuzzy finder

**Architecture:** Bubbletea-based TUI that lets users filter and multi-select tables before config generation. Selected tables populate both `include` field and filter `stats.tables` list.

**Tech Stack:** bubbletea, bubbles, lipgloss (Charm ecosystem)

---

## User Experience

### Command Usage

```bash
# Interactive mode with explicit flag
tbls scaffold --dsn "clickhouse://..." --interactive
tbls scaffold -c .tbls.yml -i
```

### TUI Interface

```
Connecting to database...
Found 47 tables. Use arrows to navigate, type to filter, Tab to select, Enter to confirm.

> users (12 cols)
  orders (8 cols)
  products (15 cols)
  events (6 cols)
  ...

Filter: ord█

Selected: 3/47
```

### Keybindings

| Key | Action |
|-----|--------|
| `↑/↓` or `j/k` | Navigate |
| `Tab` or `Space` | Toggle selection |
| `Ctrl+A` | Select all (filtered) |
| `Ctrl+D` | Deselect all |
| `Enter` | Confirm and generate config |
| `Esc` or `Ctrl+C` | Cancel |

## Generated Config

When user selects `users`, `orders`, `products`:

```yaml
# Generated by tbls scaffold
name: mydb
dsn:
  url: clickhouse://...

# Only selected tables
include:
  - users
  - orders
  - products

stats:
  enabled: true
  topN: 10
  sampleSize: 10000
  # Only selected tables appear here
  tables:
    - name: users
      mode: row_limit
      sampleSize: 10000
    - name: orders
      mode: date_filter
      dateColumn: created_at
    - name: products
      mode: row_limit
      sampleSize: 10000
```

### scaffold_tui.go Structure

```go
// tableItem represents a selectable table
type tableItem struct {
    name     string
    colCount int
    selected bool
}

// model is the bubbletea model
type model struct {
    tables       []tableItem
    cursor       int
    filter       string
    filtered     []int  // indices into tables
    quitting     bool
    cancelled    bool
}

// RunTableSelector launches TUI and returns selected table names
func RunTableSelector(tables []*schema.Table) ([]string, error)
```

### Integration in scaffold.go

```go
// After schema analysis, before GenerateScaffoldConfig
if interactive {
    selectedTables, err := RunTableSelector(s.Tables)
    if err != nil {
        return err  // User cancelled or error
    }
    if len(selectedTables) == 0 {
        // Handle no selection
    }
    // Filter schema to only selected tables
    s = filterSchemaToTables(s, selectedTables)
    // Set include in config
    c.Include = selectedTables
}
```

## Edge Cases

1. **No tables in database** - Show message "No tables found" and exit
2. **User cancels (Esc/Ctrl+C)** - Exit with message "Cancelled", no file written
3. **No tables selected + Enter** - Show warning "No tables selected. Continue anyway? [y/N]"
4. **Terminal too small** - Bubbletea handles gracefully, list scrolls
5. **Non-TTY environment with `-i`** - Error: "Interactive mode requires a terminal"
